# AI 规则版本记录

## v1.6.0 · Issue 生命周期与预约数据边界

- 新增当前 Issue 生命周期：新困扰独立计数，主动真人交接至少经过 3 次有效表达且满足最低充分判断。
- `HANDOFF_OFFERED` 改为非阻塞状态，用户继续输入时优先回应，不重复推销。
- 预约摘要只使用当前 Issue 的用户消息；飞书真实写入成功后才在浏览器本地标记预约边界。
- IndexedDB 从 v1 迁移到 v2，为旧消息补充 Issue 标记，不清除已有聊天。
- 真人交接改为多版本、基于当前困扰稳定变化的温和表达，避免重复固定话术。

## v1.5.0 · 匿名学习与人工审核闭环

- 增加匿名结构化学习事件、会话指标、用户授权后的脱敏复盘和导师反馈记录。
- 增加 `/admin/learning` 学习数据中心；洞察只生成待人工审核的候选规则，不自动修改线上 Prompt 或导诊规则。
- 增加学习数据删除接口；清空本次对话时同步请求删除该匿名会话的学习数据。
- 学习采集与实时聊天链路隔离；学习存储不可用时不阻断聊天和预约。

## v1.4.0 · 最低充分判断与快速真人交接

- 将真人交接从“信息接近完整”收紧为“够判断就交接”。
- 增加 `DIRECT_HANDOFF` 和 `QUICK_HANDOFF`，主动真人意愿不再经过普通导诊。
- 交接时停止所有补充提问，预约按钮统一为“免费预约真人聊聊”。
- 进入预约页后自动生成可编辑的当前困扰摘要，不要求用户重新描述。

## v1.3.0 · AI 导师自然对话与智能交接

- 增加回复目标、回复长度和交接状态，默认先由 AI 解决轻量问题。
- 真人导师保持隐形；只有用户主动提出或满足“问题清楚、已有基础帮助、继续 AI 收益有限”的条件时才交接。
- 交接后停止继续追问，服务端禁止模型提前提及真人、导师、预约、人工或分配。
- 增加自然度规则，降低固定共情、重复总结和连续提问。

## v1.1.0 · 2026-09-28

- 将对话状态、主题、用户意愿、服务路径和安全状态纳入结构化内部结果。
- 增加模型 JSON 输出校验和服务端关键路径覆盖。
- 增加模糊安全表达的必要澄清，不把普通情绪自动判为危机。
- 将规则拆分为系统提示、对话规则、主题分类、导诊、安全和摘要文件。
- 增加 T01-T15 多轮测试案例。
- 明确真人服务由运营人员人工分配，不提供时间选择或自动匹配承诺。

# v1.2.0 · 轻量心理导诊规则重构

- 以 Problem Map 作为内部导诊基础，维护主诉、场景、持续时间、频率、严重程度、功能影响、触发因素、已尝试方法和用户目标。
- 取消固定轮数和固定问题数量，改为只追问会改变判断、支持方式、测评选择或服务路径的信息缺口。
- 增加 `LIGHT`、`MODERATE`、`COMPLEX`、`HIGH_RISK` 复杂度，以及 `AI_SUPPORT`、`HUMAN_MENTOR`、`PROFESSIONAL_REFERRAL`、`SAFETY_SUPPORT` 四类服务路径。
- 安全信号和明确用户意愿由服务端规则优先控制；只想倾诉、拒绝测评或拒绝真人时，不强制推进下一步。
- 测评只作为降低不确定性的可选工具，不作为诊断；复杂或深层内容不由 AI 继续做 D3 深挖。
- 增加 `assessment-rules.md`，并保留旧字段映射以兼容已有前端和预约流程。
