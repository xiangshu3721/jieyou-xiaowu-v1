## 禁止行为（must_not）
1. AI 自行宣布问题已解决
2. 重复追问已回答字段
3. 把建议轮数当进展
4. 中性回应宣称有进展
5. 同轮风险被结案信号遮蔽
6. 不确定词触发结案
7. 退出意愿触发结案
8. 好转未解触发结案
